## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS

## Rodar localmente

```sh
npm i
npm run dev
```

Abra o endereço que aparecer no terminal (normalmente http://localhost:8080).

- Catálogo e preços: `src/data/products.ts`
- Dúvidas frequentes e condições: `src/data/faq.ts`
- WhatsApp e Instagram: `src/lib/whatsapp.ts`
- Rastreamento: `src/lib/tracking.ts` e a página `/rastreamento`
- Cores da marca: `src/styles.css`
